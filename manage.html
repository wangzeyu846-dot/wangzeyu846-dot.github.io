同步公众号文章

在公众号发布后，把文章链接提交一次。网站会一起更新文章列表、近期文章和文章数量。

打开文章同步入口 ↗

入口在新窗口打开。使用 wangzeyu846-dot 的 GitHub 账号登录，只有网站所有者可以执行同步。

照着做，三步完成

  1. 打开同步入口。在 GitHub 页面点击右侧 Run workflow，分支保持 main。
  2. 粘贴文章链接。可以同时填写标题、发表日期和摘要。标题与日期都填好时，会直接采用你确认的信息；添加新文章时只填链接，会尝试读取文章；已收录文章的未填写字段保留原值。
  3. 点击绿色 Run workflow。等待最新一条运行记录出现绿色对勾，再返回网站刷新。文章会按发表日期排序，同一链接再次提交会更新原记录。

这些字段怎么填

文章链接 · 必填
粘贴微信文章的公开链接，例如 https://mp.weixin.qq.com/s/…。
文章标题 · 选填
使用公众号里实际发表的标题。如果微信要求验证或无法读取，在这里补上标题。
发表日期 · 选填
按 2026-11-04 的格式填写实际日期。系统不会把提交当天当作发表日期。
文章摘要 · 选填
写一两句简短介绍即可。留空时，新文章可以只展示标题；更新旧文章时保留原摘要。

如果没有出现绿色对勾

点开最新运行记录，查看页面中的处理说明。微信有时会返回验证页面；遇到这种情况，回到入口补上标题和发表日期，再提交同一链接。

同步失败会保留原有文章。这里仅更新网站目录，读者仍点击文章进入公众号原文。
